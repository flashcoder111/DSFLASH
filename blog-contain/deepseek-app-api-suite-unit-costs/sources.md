# Sources

- **DeepSeek Platform: App API suite announcement and official price list, 13 November 2026.** The single source for this article. It provided the endpoint prices used throughout (Search and Fetch $0.75 per 1,000 calls, OCR and file parsing $0.225 per 1,000 pages, ASR $0.058 per audio hour, TTS $0.225 per 10,000 characters) and the end-of-November change from per-call billing to input-token billing for server-side search. Flash token rates in the worked example follow the published V4.1 Flash price card: $0.14 input, $0.028 cache hit and $0.28 output per million tokens.

No external hyperlinks are used in the published body. The only link is the site's own pricing page, https://deepseekv4flash.com/pricing.
