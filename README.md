# DSFlashHub

DeepSeek V4 Flash and OpenClaw intelligence site.

The site is built as a Flash-first information hub:

- DeepSeek V4 Flash pricing and cache-hit economics
- OpenClaw adaptation pages and routing rules
- Flash vs Pro escalation guidance
- GPT, Claude, Gemini, and Grok comparison pages
- Multilingual sample routes for `zh` and `ja`

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
